# BusBot – Smart Voice-Based PMPML Assistant

## 🚀 Overview

BusBot is a smart, voice-based public transport assistant designed to make bus travel completely hands-free, intuitive, and safer. The project was developed as part of the **Zero UI Challenge at Innovation 2026**, where it secured **1st place**.

Built using **Flutter**, integrated with **SQLite** and intelligent voice processing, BusBot aims to improve the commuting experience for:

* Visually impaired users
* Elderly passengers
* Everyday commuters in crowded environments

The core idea behind BusBot is simple:

> Users should be able to navigate their entire bus journey without constantly needing to interact with their phone.

---

# ✨ Features

## 🎤 Voice-Based Interaction

Users can simply speak their destination to interact with the application.

BusBot is designed to:

* Reduce manual interaction with mobile devices
* Enable hands-free commuting
* Provide an intuitive travel experience

---

## 🔊 Noise-Augmented Voice Recognition

To improve performance in crowded public transport environments, BusBot integrates noise-augmented voice processing.

This helps the system:

* Recognize commands more accurately in noisy surroundings
* Improve reliability in buses and crowded stations
* Provide a smoother voice interaction experience

---

## 🚌 Real-Time Journey Assistance

BusBot guides users throughout their journey by:

* Identifying the appropriate bus
* Providing estimated arrival information
* Estimating crowd levels
* Tracking the ongoing journey
* Vibrating to notify users before their stop arrives

This allows users to travel stress-free without constantly checking maps or screens.

---

## 🌙 Night Safety Mode

BusBot includes a Night Safety Mode focused on commuter safety.

If route deviation is detected:

* The system alerts the user
* Emergency contacts can be notified automatically if required

This feature is especially useful for late-night commuting.

---

## 🌐 Voice Interaction Optimized for Indian English

The voice interaction system is optimized for Indian English to improve accessibility and usability for local commuters.

Future scope includes:

* Multilingual support
* Regional dialect integration
* Expanded accessibility features

# 🎯 Problem Statement

Public bus commuters often face challenges such as:

* Difficulty navigating unfamiliar routes
* Missing stops during travel
* Inconvenience in crowded buses
* Limited accessibility for visually impaired and elderly users
* Safety concerns during late-night travel

BusBot was developed to address these issues through a voice-first and accessibility-focused approach.

---

# 📱 How BusBot Works

1. User speaks destination using voice commands
2. BusBot identifies suitable bus routes
3. App provides bus details and estimated arrival information
4. Journey tracking begins once onboard
5. BusBot vibrates and alerts the user before their stop arrives
6. Night Safety Mode monitors deviations if enabled
